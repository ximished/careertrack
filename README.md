# CareerTrack — Job Application Pipeline

A responsive client-side web application designed to track job applications, interviews, and offers in an organized dashboard.

**Live Demo:** [https://<your-username>.github.io/careertrack/](https://<your-username>.github.io/careertrack/)

## Key Features
- **Pipeline Dashboard**: Real-time counter metrics tracking total applications, active interview loops, and offers.
- **Search & Filter Engine**: Instant multi-attribute search and category filtering by application status.
- **Client-Side Persistence**: Saves data across browser sessions via the `localStorage` API.
- **Data Portability**: Full JSON export and backup restoration capabilities.
- **Defensive Engineering**: Input sanitization preventing XSS attacks.

## Tech Stack
- **HTML5 & Vanilla JavaScript (ES6+)**: Core DOM manipulation and state management with zero third-party framework overhead.
- **Tailwind CSS**: Modern responsive utility-first styling.
